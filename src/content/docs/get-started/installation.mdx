## Global Install

<Tabs>
<TabItem label="npm">

```bash
npm install -g @yannosay/sinth
```

</TabItem>
<TabItem label="pnpm">

```bash
pnpm add -g @yannosay/sinth
```

</TabItem>
<TabItem label="yarn">

```bash
yarn global add @yannosay/sinth
```

</TabItem>
</Tabs>

Verify the installation:

```bash
sinth version
```

## Init a Project

```bash
sinth init
```

This will launch Sinth's Project Setup Tool.

First, it will ask you what your project should be called:

```bash
✨ Welcome to Sinth project setup!

 Project name: _________
```

We will go for "My Sinth App" as an example.

Once we have selected our project name, this menu will appear:

```bash
 Select preset:
    Basic - Single page + component
  ❯ Full - Multi-page, components, SCSS demo
    Blank - Folders + config only
```

Choose the option that suits you best.

## Start Dev Server

<Steps>

1. **Scaffold**

   ```bash
   sinth init my-sinth-app
   ```

   Produces a directory with the following structure:
   
   - `pages/`            - your `.sinth` source files
   - `sinth.config.json` - project configuration

2. **Start the dev server**

   ```bash
   cd my-sinth-app
   sinth dev pages/index.sinth
   ```

   The server starts at `http://localhost:3000`. Any change to a `.sinth` file triggers instant hot reload.

   If you want a custom port, use `--port`: 
   ```bash
   sinth dev pages/index.sinth --port 3210
   ```

3. **Build for production**

   ```bash
   sinth build
   ```
   
   Specific builds:
   ```bash
   sinth build pages/index.sinth
   ```

   Custom dist folder:
   ```bash
   sinth build pages/index.sinth --out my-custom-dist
   ```

   Output lands in `dist/` (or in your custom named dist). Add `--shared-runtime` if your project has multiple pages. You can find out more about `--shared-runtime` [here](./advanced/shared-runtime.mdx).

</Steps>
